BackupSheep 插件接管漏洞

CVSS 10.0 接管 ▾
錯誤的金鑰驗證允許攻擊者下載備份並接管網站。
CVE-2026-101148BackupSheep WordPress 插件 1.8 及以下 1.8 及更早 官方補丁 ↗
The BackupSheep WordPress Backup Plugin WordPress plugin through 1.8 does not properly validate its integration key, treating an unset or blank key as valid, which allows unauthenticated attackers to create and download full site backups, including the database with user password hashes, and to delete arbitrary files on the server, leading to sensitive data disclosure and site takeover. The BackupSheep WordPress Backup Plugin WordPress plugin through 1.8 has been closed on WordPress.org since July 2024 and no fixed version is available. Remove it from any site where it is installed.
修補建議：該外掛已關閉且無修復版，建議立即從網站移除。

CVE-2026-55393Aware2 6.9.0.2 與 1.7.9 及以下版本 6.9.0.2 及更早 官方補丁 ↗
Unvalidated pathnames in the web interface in Teledyne FLIR Aware2 versions through 6.9.0.2 (PackBot) and 1.7.9 (FirstLook) allows remote unauthenticated attackers to read configuration and security parameters on Teledyne FLIR PackBot and FirstLook robots running this software via path traversal.

Fortra BoKS 密碼預測漏洞

CVSS 9.9 其他高危 ▾
隨機序列可預測導致 AD 服務帳號密碼遭破解。
CVE-2026-79901使用 BoKS keytab 管理的受影響版本 官方補丁 ↗
In deployments using BoKS keytab management, affected versions of boks_keytabmd generate Active Directory service-account passwords from a predictable pseudo-random sequence seeded with the current Unix timestamp. An attacker who knows the service principal and can estimate the password-change time can reproduce a limited candidate set and verify candidates offline.
修補建議：參考 Fortra 安全公告 FI-2026-012 進行修補。

A flaw was found in Foreman. An authenticated attacker with low-level permissions can achieve remote code execution (RCE) by bypassing the safemode sandbox within the templating engine.
